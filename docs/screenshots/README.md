# Ekran Görselleri

Ana README'nin referans verdiği ekran görsellerini buraya koyun. Önerilen
boyut: 1080x2340 (tipik telefon ekranı) veya 1280x720 (panel ekranı).

## Beklenen dosyalar

| Dosya | İçerik |
|-------|--------|
| `panel-login.png`           | Süper-admin panel login ekranı |
| `panel-orgs.png`            | Organizasyon listesi |
| `panel-admins.png`          | Admin yönetimi |
| `panel-cti.png`             | Login Attempts / CTI sayfası |
| `panel-error-logs.png`      | Hata logları |
| `mobile-login.png`          | Mobil login ekranı |
| `mobile-admin-data.png`     | Admin → Data sekmesi (akordiyon) |
| `mobile-admin-assign.png`   | Admin → Assign sekmesi |
| `mobile-admin-calendar.png` | Admin → Calendar (filtrelerle) |
| `mobile-admin-settings.png` | Admin → Settings |
| `mobile-lecturer-home.png`  | Hoca ana ekran |
| `mobile-lecturer-avail.png` | Hoca müsaitlik |
| `mobile-lecturer-sched.png` | Hoca haftalık program |
| `pdf-output.png`            | Üretilen PDF örneği |

Ekran görsellerini eklerken `screenshots/` klasörüne koymanız ve ana README'de
`docs/screenshots/<dosya>` olarak referans vermeniz yeterli. Eksik dosyalar
README'de bozuk image olarak görünür ama metin yine okunabilir.
